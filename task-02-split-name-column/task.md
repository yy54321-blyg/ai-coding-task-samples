# Task 02 · 把 CSV 的「姓名」列拆成「姓」和「名」两列

## 需求

读取一个含 `姓名` 列的 CSV，输出新 CSV：`姓名` 列被替换为 `姓` 和 `名` 两列，
**其余所有列与列顺序保持不变**。

**规则：**

1. 复姓表（共 20 个）：
   `欧阳 司马 上官 诸葛 东方 皇甫 尉迟 公孙 慕容 长孙 宇文 司徒 令狐 夏侯 端木 南宫 独孤 轩辕 百里`
2. 姓占 1～2 字
3. 空值 / 只有 1 个字：`姓` = 原值，`名` = 空字符串，并计入 `需人工确认` 计数
4. 包含空格或点号的（如 `John Smith`）：按第一个空格拆分
5. 自动探测编码：`utf-8-sig` → `utf-8` → `gbk`
6. 输出必须为 `utf-8-sig`，保证 **Excel 直接打开不乱码**

---

## 输入示例

`data.csv`

| 编号 | 姓名 | 部门 |
|---|---|---|
| 1 | 张三 | 技术 |
| 2 | 欧阳锋 | 技术 |
| 3 | 司马相如 | 市场 |
| 4 | 王五 | 市场 |
| 5 | 李 | 行政 |
| 6 | John Smith | 海外 |

## 期望输出

| 编号 | 姓 | 名 | 部门 |
|---|---|---|---|
| 1 | 张 | 三 | 技术 |
| 2 | 欧阳 | 锋 | 技术 |
| 3 | 司马 | 相如 | 市场 |
| 4 | 王 | 五 | 市场 |
| 5 | 李 | | 行政 |
| 6 | John | Smith | 海外 |

统计：完成 6 行，其中需人工确认 1 行

---

## 验收标准（可测）

- [ ] `张三` → `张` / `三`
- [ ] `欧阳锋` → `欧阳` / `锋`（**复姓不能被拆成 欧 / 阳锋**）
- [ ] `司马相如` → `司马` / `相如`
- [ ] `王五`（两字）→ `王` / `五`
- [ ] 空字符串 → 空 / 空，且计入 `需人工确认`
- [ ] `李`（单字）→ `李` / 空，且计入 `需人工确认`
- [ ] `John Smith` → `John` / `Smith`（不按单字拆）
- [ ] 输出的**列顺序**为：原列顺序中 `姓名` 的位置被 `姓,名` 替换
- [ ] 输出文件用 **Excel 打开中文不乱码**
- [ ] 输入为 `GBK` 编码时也能正确读取

---

## 难度

**中等**

涉及能力：
- CSV 读写、`DictWriter` 保持列序
- **编码探测**（UTF-8 / UTF-8-BOM / GBK）
- 领域规则建模（复姓表）
- 数据清洗中的「不确定项」处理

---

## 常见错误（AI 典型失败模式）

| # | 错误 | 正确做法 |
|---|---|---|
| 1 | **一律取第一个字当姓** → 复姓全部错误（欧/阳锋） | 先查复姓表，再走单字逻辑 |
| 2 | 用 `encoding="utf-8"` 输出 → **Excel 打开中文乱码** | 输出用 `utf-8-sig`（带 BOM） |
| 3 | 空值 `None.strip()` 直接抛 `AttributeError` | 先 `(v or "").strip()` |
| 4 | 用 `pandas` 读取后重排列顺序，`姓名` 跑到最后 | 显式按原 `fieldnames` 顺序重建 |
| 5 | 「两字姓名」当复姓处理，`王五` → `王五` / 空 | 复姓只查表，不靠长度猜 |
| 6 | 直接覆盖输入文件 | 输出到新文件 |
| 7 | `John Smith` 按每字拆成 `J` / `ohn Smith` | 存在空格时优先按空格拆 |
| 8 | GBK 文件用 UTF-8 读，报 `UnicodeDecodeError` 后直接退出 | 按编码列表依次尝试 |

---

## 为什么这个任务适合评测

- **规则复杂但完全可定义**：复姓、单字、空值、英文名，每种都有明确预期
- **存在真实的判断难点**：「两字到底是姓单字+名单字，还是复姓」，必须在题目里说清规则
- **失败方式明显**：复姓拆错、乱码、列顺序变化，都能一眼看出
- **贴近真实数据清洗场景**：中文姓名拆分是高频需求
