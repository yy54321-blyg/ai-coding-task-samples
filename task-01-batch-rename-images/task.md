# Task 01 · 批量按拍摄日期重命名图片

## 需求

读取指定目录下的图片，按**拍摄时间**重命名。

**规则：**

1. 优先使用 EXIF 中的 `DateTimeOriginal`（tag 36867）
2. 无 EXIF 时，回退到文件修改时间（mtime）
3. 新文件名格式：`YYYYMMDD_HHMMSS.ext`（扩展名统一转小写）
4. 同一秒存在多张时，追加 `_1`、`_2`……
5. 支持 `--dry-run`：只打印计划，**不修改任何文件**
6. **不覆盖**已存在的文件；目标名冲突时依次追加序号
7. 处理结束输出统计：成功 / 跳过 / 失败
8. 非图片文件、无法解析的文件**不中断整个流程**

---

## 输入示例

```
in/
├── a.jpg   (EXIF DateTimeOriginal = 2024-05-01 10:20:30)
├── b.png   (无 EXIF, mtime = 2024-05-02 08:00:00)
├── c.jpg   (EXIF DateTimeOriginal = 2024-05-01 10:20:30)
├── d.JPG   (EXIF DateTimeOriginal = 2024-05-03 09:00:00)
├── note.txt
└── broken.jpg (文件损坏，无法打开)
```

## 期望输出

```
in/
├── 20240501_102030.jpg
├── 20240501_102030_1.jpg
├── 20240502_080000.png
├── 20240503_090000.jpg
├── note.txt          ← 未改动
└── broken.jpg        ← 未改动

统计：成功 4 / 跳过 1 / 失败 1
```

---

## 验收标准（可测）

- [ ] 上述输入目录重命名后，文件名集合与期望**完全一致**
- [ ] `a.jpg` 与 `c.jpg` 同秒冲突时，其中一个变为 `20240501_102030_1.jpg`，**没有任何文件被覆盖**
- [ ] `--dry-run` 执行后，目录内**文件名集合与所有文件的 mtime 均未变化**
- [ ] `b.png` 无 EXIF 时**不报错**，正常使用 mtime 重命名
- [ ] `d.JPG` 大写扩展名能被识别，输出扩展名为小写 `.jpg`
- [ ] `note.txt` 被跳过，且计入 `跳过` 数量
- [ ] `broken.jpg` 无法打开时不抛未捕获异常，计入 `失败` 数量，**后续文件继续处理**
- [ ] 对同一目录**重复运行第二次**，文件名不再发生变化（幂等）

## 难度

**中等偏低**

涉及能力：
- `pathlib` 目录遍历与文件筛选
- 二进制文件读取 + 元数据解析（Pillow）
- 异常处理与降级策略
- 命令行参数（`argparse`）
- **幂等性设计**（重复执行结果一致）

---

## 常见错误（AI 典型失败模式）

| # | 错误 | 正确做法 |
|---|---|---|
| 1 | 直接 `os.rename`，目标同名时**静默覆盖**原文件 | 先 `Path.exists()` 检查，冲突则追加序号 |
| 2 | EXIF 缺失时 `KeyError` / 直接崩溃 | `try/except` 包裹，回退到 mtime |
| 3 | 只处理小写扩展名，`.JPG` 被漏掉 | 用 `p.suffix.lower()` 判断 |
| 4 | **`--dry-run` 只打印，但代码里仍调用了 `rename`** | dry-run 分支必须在写操作之前 `continue` |
| 5 | 同一秒多张图全部算出同一个名字，**后者覆盖前者** | 维护 `used` 集合 + 检查磁盘是否存在 |
| 6 | 一个损坏文件就让整个脚本退出 | 每个文件单独 `try/except`，累计 failed |
| 7 | **不幂等**：第二次运行把 `20240501_102030.jpg` 改成 `20240501_102030_1.jpg` | 目标名与原名相同时直接跳过 |
| 8 | 把 EXIF 时间与 mtime 混用，导致同一张图两次运行结果不同 | 明确优先级，只选一个来源 |

---

## 为什么这个任务适合评测

- **有唯一正确答案**：给定输入，输出文件名集合是确定的
- **有明确的失败方式**：覆盖、漏文件、dry-run 失效都能被检出
- **存在判断点**：EXIF 缺失怎么处理、冲突怎么编号（需要在题目里明确规定）
- **容易自动判定**：写成测试只需比对文件名集合
